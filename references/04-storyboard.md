# ④ 分镜 — storyboard.md

**输入**：`song.md`（主题、情绪、BPM、节拍点、段落）、`lyrics.srt`（时间轴）、`tests/style-choice.md`（画风）、`compositions/character.js`（角色能力）

**输出**：`storyboard.md`，然后**停下来等确认**。

## 铁律

1. **一句歌词一个镜头**。以 `lyrics.srt` 的时间轴为准 —— 不是按小节，不是按情绪段落。
2. **画面直接表现这句歌词的含义**，不是表现这句歌词的字面文字。
3. **抽象的歌词拆解为观众看得懂的连续动作**。一个动作 → 一个结果，中间不要跳。
4. **镜头切换对齐 `song.md` 里的节拍点**。切点允许 ±0.08s 微调，但不能切在节拍中间。
5. **结尾留余味**：最后一镜不要给结论，给一个「还在继续」的画面。

## 禁止

- 单句歌词安排多个动作（观众看不清，还会让镜头变长）
- 无信息量的过场（空镜必须有情绪目的，否则删）
- 观众无法理解的情节（如果需要一个解释才能懂，就是不成立）

## 文件结构（HyperFrames 能解析的格式）

HyperFrames 的 storyboard parser 认 `## Frame N — 标题` + `- key: value` 列表。**照这个格式写**，好处是 `snapshot --review` 和工具链能直接读：

```markdown
---
format: 1920x1080
duration: 62s
message: 告别不是转身，是把对方留在原处
arc: 悬停 → 低语 → 撑开 → 回撤 → 收束
audience: 听众
mode: collaborative
character: compositions/character.js @ v1
style: paper
palette: ["#2a2622", "#8a7f6d", "#b8452e", "#e8dcc4", "#d8c9a8"]
---

## Frame 1 — 前奏：空巷

- scene: 巷子空着，一只猫跳下墙，扬起一点灰
- start: 0.00
- duration: 4.20
- transition_in: cut
- beat_anchor: 4.51
- reads: 巷子没人（0.2-2.0s）；猫跳下（2.0-3.6s）
- sound: 只有环境底噪，4.0s 处一声轻落
- src: compositions/frames/01.html
- status: outline

前奏不给角色，先让人记住地方。猫的落地是第一个动作，把观众的眼睛拉到巷子深处 ——
下一镜角色从那个方向出来。
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `scene` | ✅ | 一句话画面描述，作为总览图的 caption |
| `start` / `duration` | ✅ | 秒，两位小数；`start` 必须等于上一条的 `start + duration` |
| `transition_in` | ✅ | 见 05-transition（`cut` / `whip` / `match` / `card` / `push`） |
| `beat_anchor` | ✅ | 这一镜的开头对齐的节拍点时间（从 `song.md` 抄） |
| `reads` | ✅ | 观众必须看懂的东西，按时间窗口列，窗口不重叠 |
| `sound` | ✅ | 底噪/音效/静音 |
| `src` | 分镜后填 | 对应 `compositions/frames/NN.html` |
| `status` | ✅ | `outline` → `built` → `animated` |
| 歌词 | ✅ | 单独一行 `> 歌词原文`（方便对时间轴核对） |

## 时间轴怎么排

```python
# 从 lyrics.srt 生成骨架，再人工填内容
cues = MVSrt.tighten(parse(srt_text), gap=0.12)
for i, c in enumerate(cues):
    print(f"## Frame {i+1} — \n- start: {c['t0']:.2f}\n- duration: {c['t1']-c['t0']:.2f}\n> {c['text']}")
```

然后逐条做三件事：

1. **判断这句能不能一个动作演完**。不能就承认「这句只能给静景 + 一次运镜」，别硬塞。
2. **找它对应的物理动作**。抽象词 → 具体动作的对照表见下。
3. **把切点吸附到节拍**：`beat_anchor` 取 `song.md` 里最近的节拍点，如果差 > 0.08s，把 `start` 微调到那个节拍点，同时等量缩短上一镜。

### 抽象 → 具体 对照（核心手艺）

| 歌词类型 | 不要这样演 | 这样演 |
|---|---|---|
| 「时间过去」 | 钟表指针转 | 同一张桌子，杯子里的水从满到空；阳光斑从桌左移到桌右 |
| 「想念」 | 角色捂胸口 | 角色伸手去够一个不在的东西，手指停在半空 |
| 「回不去」 | 门关上 | 角色走到门口，手放在门上，然后转身走开 |
| 「放下了」 | 松手扔掉 | 手心向上摊开，看着空手，握一下，再放开 |
| 「孤独」 | 一个人站着 | 两个杯子，只有一个在用；或角色坐在两人座的中间 |
| 「长大」 | 身高变化 | 同一件衣服，从合身到短了一截 |
| 「告别」 | 挥手 | 两个人背对走，其中一个回头看了一眼又转回去 |

规律：**用「物件的变化」和「动作的未完成」代替情绪形容词**。

## 剧本级节奏（情绪曲线）

照 `song.md` 的段落表，给每个段落定「镜头密度」和「景别」：

| 段落 | 镜头密度 | 景别 | 运动 |
|---|---|---|---|
| 前奏 | 2~4 秒一镜 | 大远景/空镜 | 极慢推 |
| 主歌 | 一句一镜（2~4 秒） | 中景 | 缓移 |
| 副歌 | 一句一镜（1.4~2.5 秒） | 中近景，情绪最强处给特写 | 一次推近或跟随 |
| 间奏 | 3~5 秒一镜 | 物件特写 | 几乎静止 |
| 桥段 | 一句一镜 | 全景 | 反向运动（前面推，这里拉） |
| 尾奏 | 一镜到底 | 大远景 | 慢拉远，留白 |

**副歌返回时换景不换戏**：同一个「家」的场景，每次副歌回来都加一件东西（多一盏灯、多一个人影），形成递进。

## 用户私人口径

用户的原文有一句：

> 以下抽象歌词按我的理解表现:（写在这里）

分镜前必须**主动问一次**（这是唯一允许的问句）：

> 「有没有哪句歌词你有具体想法？比如某句你希望它是一个特定场景。没想法的我按通用理解来。」

拿到就写进 `storyboard.md` 的独立小节，优先级高于你自己的判断：

```markdown
## 用户指定口径
- 「我把故事都写在风里」→ 满墙的便签被吹起，镜头跟着一张纸飞出窗外
```

## 完成后

1. 汇报：镜头数、总时长、最长/最短镜头、切点是否都在节拍上。
2. **停。等确认。** 确认后才进 05（转场）和 06（关键帧）。

## 检查单

- [ ] 每一句歌词都有对应 Frame，没有漏、没有合并
- [ ] 每条 `start` 与上一条 `start+duration` 严格衔接，总时长 = 音频时长
- [ ] 每个 `beat_anchor` 都能在 `song.md` 的节拍表里找到
- [ ] 每个 `reads` 的时间窗口不重叠，窗口长度 ≥ 字数/8 秒
- [ ] 抽象句都换成了具体动作（逐条检查）
- [ ] 用户指定口径已写入并遵守
- [ ] 结尾那一镜「留余味」而不是「给结论」
